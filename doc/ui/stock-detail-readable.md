# 個股圖解與白話資訊（2026-10-27）

## 需求評估與範圍

使用者要求本輪完成需求、文件與程式；測試、驗收、上版另行執行。本契約取代個股頁舊「公司事件時間軸／進階資料／四模型與事件相容基準」呈現方式，其餘頁面與資料治理不變。

問題在 Flutter presentation：公告僅列標題日期；specialist plain_language 混入大量欄位名；模型原始值、版本、缺口同時展開。既有 API 已提供可用 metrics、公告 summary、四模型 serving 狀態與估值參考區間，無須新增後端、migration、資料源、依賴或 LLM。沒有內容的公告仍如實說明，不自行補寫公司事實。

## 畫面與資料契約

- 保留報價、本人持股、既有價量／營收／EPS／估值／法人圖與筆記。後方新增「用四個角度看懂這家公司」：股價走勢、公司營運、價格評價、波動風險。圖表均附數字、單位、資料日和讀法，不用綜合分數或雷達圖製造可比性。
- 股價：specialist quant.metrics 的 return_5d/20d/60d_percent 畫以零為中心的橫條，明示為已發生報酬，各期間共用比例尺，不當預測。公司營運：revenue_trend_percent、eps_trend_percent 畫比較期變化，不能擅稱年增率或猜期別；來源口徑可展開查看。
- 估值：PE／PB 分別呈現倍數及白話定義，不跨單位共用長條。僅 valuation_reference.status=available 且有限、正值、依序排列的 lower/mid/upper 才畫唯一參考價帶；中位點按實際比例定位，日期與非目標價說明必留。無區間保留缺值。
- 風險沿現有 Risk12 正式 gate，顯近期與預測年化波動比較條；不能解讀為漲跌幅或上漲機率。原始模型版本收合，不虛構月評估／季重訓已排程。
- blocked／無日期／缺值不畫數字；stale 顯示過期的觀測事實而不稱即時，預測沿原 gate 隱藏。0 是有效觀測；NaN/Infinity 不畫。圖表附文字等價值，手機與文字放大可換行。
- 公司公告：保留去重與公告時間排序、最近兩年最多六筆，改為日期節點＋標題＋實際摘要＋「閱讀提示」。提示是公告類型的閱讀方法，不是公司結論；無摘要明示「目前只有公告標題」。發布／生效／事件日不混用，來源以小字保留。
- 「分析與報告」取代「進階資料」，四模型改為四個中文問題與可用／缺資料／過期狀態；Event 不列第五模型。技術版本、原始輸出、欄位缺口與保存報告的完整內容放「資料口徑與技術明細」，預設收合；歷史與手動分析能力不刪除、不自動呼叫模型。
